# Life in Days — requirements traceability

Status: planning artifact; no implementation, evaluation execution, credential provisioning, deployment, or production verification is claimed.

This matrix enumerates every requirement identifier currently defined in the [Product Requirements Document](../product/PRODUCT-REQUIREMENTS.md) exactly once. It connects each requirement to the [UX Specification](../design/UX-SPECIFICATION.md), real task identifiers in the [Project Tracker](PROJECT-TRACKER.md), the relevant [Implementation Plan](../architecture/IMPLEMENTATION-PLAN.md) section, and planned evidence. Tracker task status remains authoritative if it changes after this snapshot.

## Status vocabulary

- **Planning mapped; implementation not started**: the behavior is represented in planning artifacts, but no product implementation or test result is claimed.
- **Evaluation gated; execution not started**: a protocol exists, but model/integration qualification remains gated and unexecuted.
- **Deferred; intentionally absent from MVP**: the item is a controlled backlog boundary, not authorized implementation.
